Pixel Hero Maker [v.90]

Serve the game directory over local HTTP and open index.html for the Web
build. The Windows launcher serves its bundled assets on your computer.

Export saves the first idle frame as SpriteSheet.png by default. Alien Armor
hides conflicting Body tail pixels for Fire Lizard, Lizard, Merman, Furry,
and Werewolf with or without a firearm. Some Armor and Cape/Back combinations
can still show an incorrect firearm hand color.

The player reads the bundled game files and saves sprite PNGs locally.
