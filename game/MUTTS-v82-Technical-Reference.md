# MUTTS Pixel Generator [v.82] — Bolt underlay twelve-item handoff

**Status:** Experimental extension of live-user-confirmed v.81 (Cape, Fire Lizard and Apache); the nine new cases require gameplay confirmation. **Scope:** only the first 64x64 idle sprite, naked Human base + Bolt + original colors; no other firearms, equipment combinations, swatches or frames are claimed fixed.

## Authoritative baseline

- Base module: `previous-v81.wasm` SHA-256 `e168c5eb402cbf1589b427b9cd83a72b6a099c857f74ab5604710dd7f11519e3`.
- Final v82 module modifies **only WASM function 71935** (the already-integrated native underlay helper). Every other pre-existing function, including CharacterBuilder.Rebuild **5031**, native hand-color **71933** and accepted v80 Cape/Back-aware hand-color **71934**, is byte-for-byte preserved. No extra globals, exports, imports or JS GPU writers were introduced. Existing `phm_underlay_status` global 28 and its export are unchanged.
- This existing native helper still runs after the hand-color routines but before Unity texture creation, modifying selected non-firearm managed arrays with final-merge-underlay semantics. For erase (Apache), all non-firearm arrays are cleared at the target coordinate.
- All 576x928 Unity/WebGL data, framework and loader binaries remain frozen, except intended native WebGL.wasm replacement. Idle native atlas maps a top-down pixel `(x,y)` to bottom-up source array index `(927-(64+y))*576+x`.

As with v81, this does NOT make swatch variants supported: the exact fingerprint remains required.

## Diagnostics

Download `PixelHero-v82-IdleAutoHandTrace.json` in Diagnostic mode after a Bolt-equipped rebuild. `result.experimentalUnderlay.status` is 1–12 above, -1 invalid managed input, -2 unsupported firearm alpha mask, -3 unmatched source sprite, -4 missing opaque color source, -5 firearm occlusion, or 0 before initialization. `observedSpriteAtlas` is read-only and may represent a different rebuild. A native status does not establish a successful actual exported PNG.

## Reproduction and test coverage

Source ZIP contains `previous-v81.wasm`, `prototype/native_underlay_v82.c`, `prototype/native_underlay_v82.wasm`, `patch_native_underlay_v82.py`, `generate_v82_rules.py`, `prototype/test_native_v82_integrated.js`, fixtures and unchanged prior tests. Compile helper with Clang wasm32 `-O2 -nostdlib -Wl,--no-entry -Wl,--import-memory -Wl,--export=phm_native_underlay`; patcher SHA-gates v81 source and swaps only method body 71935, preserving all other code sections. Rebuild Windows launcher from Go source embedding the same `game/` tree distributed for Web.

Tests completed: 12 exact-native-fixture output matches excluding deliberate source PNG alpha hand-marker discrepancies, 12 unmatched-outfit safe skips, 12 non-Bolt mask skips, and invalid managed slot skip (37). Browser/export/hand-color synthetic regression and binary verification are separate; they cannot prove actual live Unity selection combinations. Original three cases were accepted by user on v81, while nine are newly experimental. Windows runtime on Windows, real human-clicked Save dialog, and actual browser-saved ZIP basenames are NOT TESTED if unavailable. Other firearms and tails remain outside this release scope.

Release formatting follows `MUTTS_PIXEL_GENERATOR_PROJECT_RELEASE_RULES.md`: exact `MUTTS Pixel Generator [v.82]` title, flat archives with literal spaces/brackets, `SpriteSheet.png` default, historical changelog preserved, Windows/Web embeds identical runtime files. Do not assume this twelve-item rule set is universal for arbitrary gear.
